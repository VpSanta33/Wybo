# Wybo · 望月小铺前端

React 18 + TypeScript + Vite。根据用户指定的 [GPTibo](https://gptibo.com/) 参考，采用极简的双栏选购界面：浅灰背景、蓝色选中态、白色下单卡片与原创蓝色月兔 SVG。

```bash
npm install
npm run dev
npm run build
```

## 页面与交互

- `/`：顶部商品类别切换、左侧产品品牌主图与月兔点缀、右侧商品套餐、数量调整、接收邮箱、支付方式说明、购买条款、总价与订单确认。
- 商品说明可展开；售罄商品和超库存数量不可下单；支持键盘切换分类、表单标签、行内校验、焦点管理和减少动画偏好。
- 确认弹窗先展示商品、数量、邮箱及金额，再提交订单。正式商品支持优惠码，最终优惠以后台创建订单的金额为准。
- `/orders`：订单号与原联系方式查询、最近十笔订单、卡密领取与复制、待付款订单继续支付或取消。
- `/guide`：购买流程、常见问题和帮助中心。
- 手机采用纵向排版，平板与桌面采用双栏布局。无远程图片或字体依赖。

## 本地预览

```bash
npm run dev -- --port 5175
VITE_DEMO_MODE=true npm run dev -- --port 5176
```

5175 使用后端数据；5176 强制演示。后端不可用或无商品时自动使用带「演示预览」标记的样例数据。

Vite 将 `/api`、`/uploads` 代理到 `http://127.0.0.1:8080`。也可通过 `VITE_API_BASE_URL` 指定 API 前缀，参见 `.env.example`。

演示订单仅存于当前标签页内存，不向后端提交、不产生扣款或真实卡密，刷新后失效。最近订单列表保存在当前浏览器 localStorage，不包含邮箱等联系方式。

真实商品使用 `/api/v1/orders` 创建订单，使用 `/orders/:orderNo?contact=...` 查询。支付调用已有 `epay` 网关，跳转到后台返回的 HTTP(S) 收银台；需要先在后端配置并启用网关。界面不虚构 USDT 等尚未接入的支付方式。

生产环境需配置 SPA fallback 到 `index.html`，并反向代理 `/api` 与 `/uploads` 到后端。样例商品和价格仅用于演示。

## 品牌图片与多套餐

- ChatGPT、Claude、Grok、Gemini 的 SVG 图片保存在 `public/brands/`，来源与许可证同目录记录。导航、产品主图和套餐缩略图使用相同的品牌识别。
- 后台 `cover` 字段配置的自定义图片优先作为主图；加载失败回退到品牌图。
- ChatGPT Plus 与 Pro 5x / 20x / 50x 分别对应独立的后台商品 ID。价格、库存与描述均读取后端，不在前端写死正式售价。
- 价格为 `0` 表示「待定价」，可选中查看，但不能创建订单；前端和后端均拦截未定价商品。配置正数价格并导入卡密库存后即可购买。
- 已在本地数据库初始化三个 Pro 套餐。其他环境可在 `backend/` 执行 `go run ./cmd/init-plans`，重复执行会保留已有商品和价格。
- 管理接口沿用 `PUT /api/v1/admin/products/:id`，金额单位是分；将 `price_cents` 设为正数即可定价，图片用 `cover` 字段配置。
