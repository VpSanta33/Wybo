# Payment provider marks

Local assets identify payment providers. Runtime pages do not request third-party image URLs.

- `stripe.svg`: Stripe mark from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/stripe.svg), CC0; rendered in Stripe purple `#635bff`.
- `dujiaopay.webp`: icon portion of the [DujiaoPay official site](https://www.dujiaopay.com/) wordmark, obtained from its public `/public/branding` endpoint on 2026-11-01. Original: `https://www.dujiaopay.com/uploads/61890f0c-1434-4e50-9e99-ad6d3feb4ae0`. Cropped with padding and resized, without changing the brand drawing.
- `bepusdt.svg`: [BEpusdt project mark](https://github.com/v03413/BEpusdt/blob/main/static/checkout/official/assets/img/bepusdt.svg), from the GPL-3.0 project (only trailing whitespace normalized); see the included [upstream license](BEpusdt-LICENSE.txt).
- `epay.svg`: original Wybo illustration of the Chinese character 易 for the generic Epay protocol. This does not identify or endorse a particular Epay service provider.

Brand names and marks belong to their respective owners and identify the configured integrations.
