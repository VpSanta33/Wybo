# 青屿集 · Qingyu 设计规范

## 品牌与视觉方向

- 默认中文品牌名：`青屿集`（`site_name`）；品牌短名：`Qingyu`（`site_brand`）。
- 视觉语言：深青海域（`#0F4C52` / `#0B3E44` / `#196F77`）、柔白表面（`#F4F7F6` / `#FFFFFF`）、海沫浅青点缀（`#8CDAD1` / `#EAF5F3`）、岛屿剪影与双重浪线品牌标记（`QingyuMark`、`IslandVisual`）。
- 字体使用系统无衬线与中文系统字体，无外部字体请求；价格、数量、订单号、统计指标统一使用 `tabular-nums`。
- 买家端、商家后台、分站后台与分站申请页均优先读取公共站点配置（`site_name`、`site_brand`、`site_logo`、`site_favicon`），不在导航或页脚写死主站品牌名。
- 产品品牌 SVG（`/brands/*.svg`）与支付渠道标识（`/payments/*`）保持原样，自定义商品封面与站点图片优先，加载失败时平滑回退到品牌图或海岛插画。

## 商店前台结构与交互

- 顶部采用双层结构：顶栏展示动态品牌标志与文字（`SiteBrand`）及实用入口（帮助中心、我的订单）；下方独立类目导航坞（`.category-dock`）承载横向分类切换栏。
- 分类导航保持 `tablist` / `tab` / `tabpanel` 语义，支持方向键、`Home`、`End` 键盘导航、溢出左右浏览按钮、触屏横向滑动及 `min-height: 44px` 触控热区；选中类目使用深青主色高亮。
- 桌面并排展示商品详情和下单表单。左侧的海岸横幅显示商品名称、发货方式与图片，优先使用商家上传的封面，其次使用产品标识或海岛插画。商品说明和标签位于横幅下方。
- 右侧依次展示套餐及价格、邮箱与数量、支付方式与订单合计。手机上表单位于紧凑的商品预览下方，完整的使用与兑换说明可在表单底部展开。
- 订单查询页（`/orders`）与购买指南（`/guide`）沿用同一深青与柔白卡片体系；确认订单、帮助中心、条款与隐私使用原生 `<dialog>` 管理焦点与 `Escape` 关闭，支持 `prefers-reduced-motion: reduce`。
- 保持原有前端路由、分页全量商品加载、代理归属、`Turnstile` 验证、`待定价` 禁购与真实支付流转规则不变。
