# 商家后台页面规范

沿用 Wybo 月兔品牌，面向日常经营采用低干扰的浅色工作台。已应用 UI UX Pro Max 的 dashboard 布局、响应式表单与图表建议。

- 桌面：232px 固定白色侧栏，73px 顶栏，主区背景 #f5f7fb；中心内容最大 1600px，36px 间距。
- 指标四列，经营趋势 + 待办双栏；1000px 以下图表纵排，760px 以下抽屉导航，手机指标两列。
- 白色表面、10px 圆角、浅边框、轻阴影。蓝色用于操作与收入、绿色用于利润、紫色用于订单、暖黄用于库存。
- 系统字体，正文 13–14px，标题 25px，数字 28px；字段持续标签、提示和错误反馈。
- Lucide SVG 图标，BunnyMark 用于品牌，Moon 用于轻量点缀。
- 成本/售价同时展示。待定价、未知成本、无成交和缺失配置有明确空态，不使用虚假曲线和营业记录。
- 原生 dialog 管理焦点、支持 Escape，保存中锁定按钮；支持密码管理器与粘贴验证码。QR Code 本地生成。
- 卡密默认遮罩；密钥 API 输出遮罩，保存空值保持旧密钥。支付前台仅读取启用渠道。
- 图表使用 Recharts，每日实际数值、图例和 tooltip。UV 为每日去重后跨日累加。
- 小屏表格在自身容器横向滚动，不撑开页面；侧栏高度不足时可滚动；支持 reduced-motion。

## 经营扩展页面

- 沿用现有布局与系统字体；财务、对账、营销、工单、结算及运维均使用统一页面标题、指标卡、表格、空态和原生弹窗。
- 主导航独立滚动，增加条目后仍可在手机抽屉与矮屏访问全部页面；自动任务放在日志与运维的页内切换中。
- 主导航按经营分析、商品库存、订单售后、渠道与营销、支付管理、系统设置分为可折叠二级菜单。按账号权限过滤子项，空分组隐藏；当前页面所在分组自动展开，展开偏好按管理员保存在浏览器。原生按钮支持键盘展开，折叠子项不参与焦点顺序，手机选择页面后关闭抽屉。
- 经营净利润展示手续费和佣金，未知资料明确提示「待补全」，估算费用有说明；未发货退款的商品成本记零。
- Stripe 退款与外部退款登记、外部代理转账登记均需在产品中明确确认，结果不确定时保留待确认状态。
- 代理工作台采用同一月兔品牌，订单售后使用紧凑折叠工单列表，保持卡密和支付操作优先展示。

## 上线与经营扩展

- 六个新页面沿用浅色表面、蓝色反馈、紧凑指标和可滚动表格。导航按经营、订单与售后、库存与采购、营销与结算、系统设置排序，并按实际服务端权限显示。
- 上线检查使用逐项检查卡片，配置和验证状态分别标记；转化使用四步数字卡、进度条与分来源表格，无数据时不绘制虚假趋势。
- 成员角色卡说明权限范围；密码和 2FA 的二次验证使用独立原生模态框。卡密明文仅通过用户主动查看后获取，隐藏时清理组件缓存。
- UI UX Pro Max 检索 `dashboard keyboard focus modal` 匹配焦点可见及焦点不被遮挡规则。新增页面已检查 375px / 812px 布局，表单使用持续标签，切换按钮有 aria-pressed。

## 站点设置

- 使用基本信息、下单防护、邮件与推送、支付地址四个标签，URL 保留当前分类；左右方向键 / Home / End 切换焦点和内容，小屏为两列标签。
- 各标签独立保存，保留其他分类未保存的编辑并显示圆点提示；上传 / 保存期间锁定分类切换。
- 品牌上传使用统一预览、大小格式提示和恢复默认入口；名称、Logo 与浏览器图标来自公共站点配置。
- Turnstile 默认关闭，密钥采用持续标签与遮罩；确认订单时加载紧凑组件，加载或验证失败明确提示并锁定提交。

## 商品图片与发货

- 商品编辑使用图片上传、实时预览、更换与恢复默认；上传期间禁止保存和关闭弹窗，保留格式 / 大小提示。
- 商品与分类提供独立删除按钮、确认弹窗、失败说明和成功反馈；UI UX Pro Max 检索 `destructive action confirmation` 匹配确认弹窗及操作结果反馈。
- 发货方式在编辑器选择，在商品列表和前台明确显示；订单详情根据下单快照显示手工内容输入或库存补发，核对勾选后才能提交。

## 代理分站

- 复用现有浅色表面、蓝色反馈与系统字体。UI UX Pro Max 检索 `reseller commerce dashboard` 匹配 Minimalism & Swiss Style；沿用已有设计规范，不引入其通用营销布局及新字体。React 检索结果面向 React 19，本项目 React 18 继续使用受控表单与显式提交状态。
- 主站以分站列表、申请审核切换组织内容；商品授权在带搜索的弹窗中逐项保存。激活链接仅在生成时展示，复制操作有反馈。
- 分站提供独立导航与浅色工作台；手机导航自动排为三列，表格仅在容器内滚动。申请页桌面双栏、手机单栏，持续标签与错误反馈清晰可见。
- 首次加载站点归属后再决定后台路由，避免误展示主站登录页。暂停状态保留查单与售后说明，并锁定新订单入口。
